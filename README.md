# NoteMark

一款开源笔记软件。

## 项目简介

NoteMark 用“星球”来组织学习：一个星球就是一个学习主题，遇到不会的知识点就做标记，点开标记进入新的星球继续学，一层层往下钻，直到把这个知识点彻底搞懂。

## 技术栈

- 后端：Spring Boot
- 前端：Vue
- 数据库：MySQL

## 核心概念：星球模型

- **星球 = 学习主题**：网页上一个大星球就是一个学习主题。
- **星球里放文件**：点进星球，可以放入多个不同格式的文件：md、图片、视频、pdf 等。
- **标记 = 不会的知识点**：学习时遇到不会的知识点，对它进行标记。
- **点击标记进入新星球**：新星球里可以放多个不同类型、不同格式的资料，对这个知识点进行讲解和补充。
- **递归嵌套**：第二个星球同样可以进行标记，点开进入第三个星球，如此一层层嵌套下去。

## 使用流程

1. 创建一个星球，作为一个学习主题。
2. 往星球里放入多个不同格式的学习文件（md、图片、视频、pdf 等）。
3. 学习时遇到不会的知识点，打上标记。
4. 点击标记，进入为这个知识点新建的星球。
5. 在新星球里放入多个不同格式的讲解、补充资料。
6. 新星球里遇到新的不会的点，继续标记、继续进入下一层星球。

## 原型演示

`demo/index.html` 是单文件 Vue 3 主界面原型，不用安装、不用打包，浏览器直接打开即可运行（需要联网加载 Vue CDN）。包含：

- 大星球主界面与学习主题
- 星球内的多格式文件列表（md、图片、视频、pdf）
- 点击标记进入子星球，面包屑路径与返回上一层
- 输入不会的知识点，添加标记并生成新的子星球

数据为演示占位，真实项目接入后替换。

## 路线图

- **第一阶段：星球与文件**：创建星球（学习主题）；星球内放入多个不同格式文件；按格式区分展示（md、图片、视频、pdf）。
- **第二阶段：标记与子星球**：对不会的知识点打标记；点击标记进入新星球；新星球内放多格式讲解补充资料。
- **第三阶段：递归嵌套与导航**：子星球可继续标记、进入更深星球；面包屑路径与返回上级；星球层级管理。
- **第四阶段：检索与整理**：按标记、星球搜索；标注与笔记导出；知识星球图谱视图。
- **远期（待定）**：账号同步、多设备、多人协作。
