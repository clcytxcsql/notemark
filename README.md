# NoteMark

一款开源笔记软件。

## 项目简介

NoteMark 的目标是让笔记和标注不再局限于某一种文件类型：无论是 Markdown 文档、PDF，还是视频，都可以在同一处做标记、写笔记，并把这些笔记与注释统一管理起来。

## 核心功能

- **多格式标记**：支持对 Markdown、PDF、视频等多种格式的内容进行标记。
- **多种格式的笔记注释**：针对标记内容创建笔记与注释，笔记本身也支持多种格式。
- **笔记统一管理**：所有标记和注释集中存放，方便回顾、检索与整理。

## 使用场景

- 阅读 PDF 论文、文档时做高亮与批注。
- 看视频课程时在关键时间点记录笔记。
- 整理 Markdown 学习资料时随手标记重点。
